# Bank Customer Churn Prediction

## Overview

This project develops a machine learning system to predict whether a bank customer is likely to leave the bank.

The main purpose of this project is to ultimately help me understand how to write maintainable Python data analysis projects instead of just sticking to notebook files

## Objectives

* Explore and validate the customer dataset.
* Build a reproducible preprocessing workflow.
* Compare multiple classification algorithms.
* Investigate the effect of resampling techniques such as SMOTE.
* Evaluate models using metrics appropriate for imbalanced classification.

## Current status

The exploratory analysis and initial model comparisons are complete. The project is being refactored into a maintainable Python package.

## Technology stack

* Python
* pandas and NumPy
* scikit-learn
* imbalanced-learn
* Matplotlib and Seaborn

## Getting started

Clone the repository, install its dependencies, and follow the setup instructions in the project documentation.

## Project structure

* `notebooks/` — exploratory analysis and experiments.
* `src/` — reusable project code.
* `tests/` — automated tests.
